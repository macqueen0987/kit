## Global Constraints

- 색은 kit 토큰만 사용한다. Tailwind 기본 컬러 팔레트(`bg-red-500` 등)는 번들에 포함하지 않는다. (스펙 §6.1)
- 임의값(`text-[13px]`, `bg-[#fff]`)은 선컴파일 방식에서 생성 불가능하다. 탈출구는 서비스 CSS에서 `var(--color-*)`를 직접 쓰는 것이다. (스펙 §6.2)
- 토큰 *값* 변경은 파괴적 변경이 아니다. 토큰·컴포넌트 클래스의 **삭제 또는 개명**만 major를 올린다. (스펙 §8.3)
- 토큰 이름은 Tailwind v4 `@theme` 규약을 따라 `--color-*` 접두사를 쓴다. 소비 서비스가 쓰던 `--bg` 같은 짧은 이름은 서비스 쪽 shim에서 매핑한다.
- accent는 L=0.780 고정, hue만 서비스별로 바꾼다. (스펙 §5.2)
- 다크 전용이다. 라이트 테마 토큰을 만들지 않는다.
- 모든 커밋 메시지는 한국어 본문으로 쓰고, 기존 저장소 관례(`docs:`, `feat:`, `fix:` 접두사)를 따른다.

## 스펙에서 조정한 것

계획을 쓰면서 파일럿 대상을 실제로 열어본 결과 두 가지를 조정했다. **스펙 문서에도 반영해야 한다 (Task 7).**

1. **`safelist.txt` → `bundle/src/safelist.css`** — 스펙 §4는 safelist를 텍스트 파일로 적었으나, Tailwind v4의 safelist 기제는 CSS 안의 `@source inline()` 디렉티브다. 별도 텍스트 파일을 두면 CSS로 옮기는 변환 단계가 하나 더 생긴다. CSS 파일 하나로 합친다.

2. **agent-gate 파일럿의 범위 축소** — 스펙 §9-2는 "agent-gate 파일럿"이라고만 적었으나, 실제로는 `dashboard.css` 1493줄이 전부 손으로 쓴 시맨틱 CSS(`.sidebar`, `.nav-item`, `.live-head`)이고 `dashboard.js` 1120줄이 그 클래스 이름으로 DOM을 생성한다. 전면 유틸리티 전환은 JS까지 다시 써야 하므로 "파일럿"의 크기가 아니다.

   대신 두 단계로 쪼갠다. **Task 5**는 `:root` 토큰만 kit으로 갈아끼운다(HTML·JS 무변경). **Task 6**은 JS가 건드리지 않는 패널 하나만 유틸리티로 전환해 safelist를 실전에서 때려본다. 이 조합이 "토큰 계약 검증 + safelist 구멍 발견"이라는 파일럿의 목적을 그대로 달성하면서 되돌리기도 쉽다.

3. **Jinja 패키지는 이 계획에서 제외한다** — 스펙 §9-1은 1단계에 매크로를 포함했으나, `agent-gate`는 Jinja가 아니라 FastAPI `FileResponse`로 정적 HTML을 내보낸다. 이 계획 안에 매크로의 소비자가 없다. 소비자 없이 8개 매크로를 만들면 검증되지 않은 API가 굳는다. **`itad` 계획(스펙 §9-4)으로 넘긴다.**

```js
// oklch → 선형 sRGB. 계수는 Björn Ottosson의 OKLab 정의를 따른다.
export function oklchToLinearRgb(L, C, H) {
  const h = (H * Math.PI) / 180;
  const a = C * Math.cos(h);
  const b = C * Math.sin(h);

  const l_ = L + 0.3963377774 * a + 0.2158037573 * b;
  const m_ = L - 0.1055613458 * a - 0.0638541728 * b;
  const s_ = L - 0.0894841775 * a - 1.2914855480 * b;

  const l = l_ ** 3;
  const m = m_ ** 3;
  const s = s_ ** 3;

  return [
    4.0767416621 * l - 3.3077115913 * m + 0.2309699292 * s,
    -1.2684380046 * l + 2.6097574011 * m - 0.3413193965 * s,
    -0.0041960863 * l - 0.7034186147 * m + 1.7076147010 * s,
  ].map((v) => Math.min(1, Math.max(0, v)));
}

// WCAG 2.x 상대 휘도. 입력이 이미 선형이므로 감마 역변환은 하지 않는다.
export function relativeLuminance([L, C, H]) {
  const [r, g, b] = oklchToLinearRgb(L, C, H);
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

export function contrastRatio(fg, bg) {
  const a = relativeLuminance(fg);
  const b = relativeLuminance(bg);
  const hi = Math.max(a, b);
  const lo = Math.min(a, b);
  return (hi + 0.05) / (lo + 0.05);
}

export function wcagLevel(ratio) {
  if (ratio >= 7) return 'AAA';
  if (ratio >= 4.5) return 'AA';
  if (ratio >= 3) return 'AA Large';
  return 'fail';
}
```

```js
// tokens.css에서 oklch 색 토큰만 뽑는다. 폰트·radius는 무시한다.
const OKLCH = /--color-([a-z0-9-]+)\s*:\s*oklch\(\s*([\d.]+)\s+([\d.]+)\s+([\d.]+)\s*\)/g;

export function parseTokens(cssText) {
  const out = new Map();
  for (const m of cssText.matchAll(OKLCH)) {
    out.set(m[1], [Number(m[2]), Number(m[3]), Number(m[4])]);
  }
  return out;
}

// 스펙 §5.2. L은 0.780으로 고정하고 hue만 돌린다.
```
